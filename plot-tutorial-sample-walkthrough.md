# Tutorial walkthrough: sample data showcase

This walkthrough uses the bundled sample files under `samples/` to demonstrate how the PLOT app reads, plots, and exports scientific data.

## Sample set used in the tutorial

- `QCM_Hysteresis.xlsx`
- `BeerLambert_Calibration.xlsx`
- `Damped_Oscillation.xlsx`
- `UVVis_Spectra.xlsx`
- `Impedance_Bode.xlsx`
- `Solar_Cell_IV.xlsx`
- `Raman_Spectroscopy.xlsx`

## Step 1 — Open the app

Open `index.html` in a modern browser and use the sample picker to load a dataset.

## Step 2 — Inspect the chart

Check axis labels, series names, error bands, and callouts. Switch theme and language to confirm both FA/EN modes.

## Step 3 — Export

Use the PNG export, SVG export, or clipboard copy button to get a clean figure for slides or documents.

## Step 4 — Repeat for other samples

Load another workbook from the sample list and repeat the inspection and export steps.

## Promo notes

The gallery PNGs under `gallery/` are a good source for promo screenshots because they are generated from the same chart engine used by the app.

## What to verify after generating assets

- All sample files import cleanly.
- Gallery PNGs look consistent with the current app state.
- Tutorial copy still matches the real feature set shown in the UI.
